# Network Topology Lab

Cisco Packet Tracer simulations covering multi-subnet LAN/WAN design, VLAN segmentation, inter-VLAN routing, and dynamic routing protocols.

---

## What's in This Repo

| File | Description |
|------|-------------|
| `*.pkt` | Packet Tracer topology files |
| `diagrams/` | Network diagrams and topology screenshots |
| `configs/` | Router and switch configuration exports |
| `notes/` | Lab notes and troubleshooting documentation |

---

## Topics Covered

- VLAN creation and trunk configuration
- Inter-VLAN routing via Layer 3 switch and router-on-a-stick
- OSPF and RIP dynamic routing protocol configuration
- Subnetting and IP addressing schemes
- End-to-end connectivity testing and fault isolation

---

## Lab Highlights

### Multi-Subnet LAN/WAN Topology
Designed a network with multiple VLANs across separate subnets. Configured inter-VLAN routing and tested connectivity between hosts on different segments. Used OSPF to propagate routes between routers across a simulated WAN link.

### Fault Isolation Exercise
Intentionally misconfigured routing and VLAN assignments to practice systematic troubleshooting. Used `ping`, `tracert`, and `show` commands to diagnose and resolve connectivity failures.
